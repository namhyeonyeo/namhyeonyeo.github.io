# SRE Troubleshooting Casebook

**Evidence label:** SANITIZED PRODUCTION INCIDENT NOTES

The cases in this folder are derived from the supplied weekly issue history. Customer names, cluster names, case numbers, exact addresses and identifying timestamps were removed.

The purpose is to demonstrate **investigation reasoning**, not to publish customer incident records.

Each case follows:

```text
Symptoms
 -> hypotheses
 -> evidence
 -> root cause
 -> recovery / mitigation
 -> validation
 -> lesson / prevention
```

Before publishing, review every sentence and confirm that the remaining level of detail is allowed by your employment/customer confidentiality obligations.
